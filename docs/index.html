Architecture

Neleus uses a layered architecture where performance-critical code runs in Rust, while strategy logic stays in Python.

Strategy Layer (Python)

Your trading logic written in Python. Easy to write, test, and iterate.

PyO3 Bridge (Rust)

Zero-cost bindings between Python and Rust. Type-safe interface.

Core Engine (Rust)

Order execution, position tracking, PnL calculation. Compiled to native code.

Market Adapters (Rust)

Exchange connectivity (Hyperliquid, Lighter). Low-latency networking.

Why This Design?

Neleus (Python + Rust)

  • Strategy logic in Python - Easy to write and modify
  • Core execution in Rust - Native speed
  • Best of both worlds - Productivity + Performance
  • Sub-microsecond latency - HFT-grade (0.9μs)
  • Type safety - Catch errors at compile time

⚠️ Python Frameworks (Backtrader, Zipline, etc.)

  • 10-100x slower - CPython interpreter bottleneck
  • GIL limitations - Single-threaded execution
  • Higher latency - Milliseconds vs microseconds
  • Memory overhead - Python object allocation
  • Not suitable for HFT - Too slow for high-frequency

Getting Started

Installation

$ pip install neleus

Create a Project

$ neleus create my-trading-bot
$ cd my-trading-bot

Create a Strategy

$ neleus new strategy --name MyStrategy

This creates:

  • strategies/mystrategy.py - Your strategy code
  • configs/mystrategy.yaml - Strategy parameters

Run a Backtest

$ neleus backtest --strategy mystrategy

Neleus will:

  1. Fetch historical data from exchanges
  2. Run your strategy on real market data
  3. Calculate performance metrics (returns, Sharpe, drawdown)
  4. Display detailed results

Writing Strategies

Strategy Basics

Every Neleus strategy inherits from the Strategy base class and implements three key methods:

from neleus import Strategy, StrategyContext, Bar, OrderSide
from decimal import Decimal

class MyStrategy(Strategy):
    def __init__(self, param1=10, param2=0.02):
        super().__init__()
        # Initialize your parameters
        self.param1 = param1
        self.param2 = Decimal(str(param2))
        self.state = []
    
    def on_start(self, ctx: StrategyContext):
        """Called once when strategy starts"""
        print(f"[{self.strategy_id}] Starting...")
    
    def on_data(self, ctx: StrategyContext, data):
        """Called for each market data event"""
        if isinstance(data, Bar):
            # Your trading logic here
            self.state.append(Decimal(str(data.close)))
            
            if len(self.state) > self.param1:
                # Place orders
                ctx.market_order(data.instrument_id, OrderSide.Buy, 0.1)
    
    def on_stop(self, ctx: StrategyContext):
        """Called when strategy stops"""
        print(f"[{self.strategy_id}] Stopped")

Key Concepts

1. Use Decimal for Precision

Important: Always use Decimal for price calculations to avoid floating-point errors.

#   Wrong - floating point errors
price = data.close * 1.01

#   Correct - precise decimal arithmetic
price = Decimal(str(data.close)) * Decimal("1.01")

2. Market Data Types

Your strategy receives different types of market data:

  • Bar - OHLCV candlestick data
  • TradeTick - Individual trades
  • OrderBook - Bid/ask orderbook snapshot
def on_data(self, ctx: StrategyContext, data):
    if isinstance(data, Bar):
        # Process candlestick data
        open_price = Decimal(str(data.open))

        volume = data.volume
    
    elif isinstance(data, TradeTick):
        # Process individual trades

    elif isinstance(data, OrderBook):
        # Process orderbook
        best_bid = data.bids[0].price if data.bids else None
        best_ask = data.asks[0].price if data.asks else None

Use the StrategyContext to interact with the market:

# Market order (immediate execution at current price)

Example Strategies

1. Momentum Trading Strategy

A simple momentum strategy that buys when price momentum is positive and sells when negative.

from decimal import Decimal
from neleus import Strategy, StrategyContext, Bar, OrderSide

class MomentumStrategy(Strategy):
    """
    Buy when momentum > threshold
    Sell when momentum < -threshold
    
    Momentum = (current_price - old_price) / old_price
    """
    
    def __init__(self, lookback=20, threshold=0.02, position_size=0.1):
        super().__init__()
        self.lookback = lookback
        self.threshold = Decimal(str(threshold))
        self.position_size = Decimal(str(position_size))
        
        self.closes = []
        self.position = Decimal("0")
        self.instrument = None
    
    def on_data(self, ctx: StrategyContext, data):
        if not isinstance(data, Bar):
            return
        
        self.instrument = data.instrument_id
        self.closes.append(Decimal(str(data.close)))
        
        # Keep only lookback periods
        if len(self.closes) > self.lookback + 1:
            self.closes = self.closes[-self.lookback - 1:]
        
        # Need enough history
        if len(self.closes) < self.lookback + 1:
            return
        
        # Calculate momentum
        old_price = self.closes[-self.lookback - 1]
        current_price = self.closes[-1]
        momentum = (current_price - old_price) / old_price
        
        # Trading signals
        if momentum > self.threshold and self.position < self.position_size:
            # Positive momentum - buy
            trade_size = self.position_size - self.position
            ctx.market_order(self.instrument, OrderSide.Buy, float(trade_size))
            self.position += trade_size
            
        elif momentum < -self.threshold and self.position > -self.position_size:
            # Negative momentum - sell
            trade_size = self.position + self.position_size
            ctx.market_order(self.instrument, OrderSide.Sell, float(trade_size))
            self.position -= trade_size

2. Mean Reversion Trading Strategy

Buy when price is significantly below average, sell when significantly above.

from decimal import Decimal
import statistics
from neleus import Strategy, StrategyContext, Bar, OrderSide

class MeanReversionStrategy(Strategy):
    """
    Buy when price < MA - (threshold * std_dev)
    Sell when price > MA + (threshold * std_dev)
    """
    
    def __init__(self, lookback=20, threshold=2.0, position_size=0.2):
        super().__init__()
        self.lookback = lookback
        self.threshold = Decimal(str(threshold))
        self.position_size = Decimal(str(position_size))
        
        self.closes = []
        self.position = Decimal("0")
        self.instrument = None
    
    def on_data(self, ctx: StrategyContext, data):
        if not isinstance(data, Bar):
            return
        
        self.instrument = data.instrument_id
        self.closes.append(Decimal(str(data.close)))
        
        if len(self.closes) > self.lookback:
            self.closes = self.closes[-self.lookback:]
        
        if len(self.closes) < self.lookback:
            return
        
        # Calculate moving average
        ma = sum(self.closes) / Decimal(len(self.closes))
        
        # Calculate standard deviation
        variance = sum((p - ma) ** 2 for p in self.closes) / Decimal(len(self.closes))
        std_dev = variance.sqrt()
        
        current_price = self.closes[-1]
        
        # Calculate z-score (how many std devs from mean)
        z_score = (current_price - ma) / std_dev if std_dev > 0 else Decimal("0")
        
        # Trading signals
        if z_score < -self.threshold:
            # Price is significantly below MA - oversold, buy
            target = min(self.position_size, Decimal("0.5"))
            trade_size = target - self.position
            
            if abs(trade_size) > Decimal("0.001"):
                ctx.market_order(self.instrument, OrderSide.Buy, float(abs(trade_size)))
                self.position = target
        
        elif z_score > self.threshold:
            # Price is significantly above MA - overbought, sell
            target = max(-self.position_size, Decimal("-0.5"))
            trade_size = target - self.position
            
            if abs(trade_size) > Decimal("0.001"):
                ctx.market_order(self.instrument, OrderSide.Sell, float(abs(trade_size)))
                self.position = target

3. Simple Market Making Strategy

Provide liquidity by placing bids and asks around the mid-price.

from decimal import Decimal
from neleus import Strategy, StrategyContext, OrderBook, OrderSide

class SimpleMarketMaker(Strategy):
    """
    Places limit orders on both sides of the orderbook
    Earns the bid-ask spread
    """
    
    def __init__(self, spread_bps=10, order_size=0.1, max_position=1.0):
        super().__init__()
        self.spread_bps = Decimal(str(spread_bps))
        self.order_size = Decimal(str(order_size))
        self.max_position = Decimal(str(max_position))
        
        self.instrument = None
        self.active_orders = []
    
    def on_data(self, ctx: StrategyContext, data):
        if not isinstance(data, OrderBook):
            return
        
        self.instrument = data.instrument_id
        
        # Cancel all existing orders
        for order_id in self.active_orders:
            ctx.cancel_order(order_id)
        self.active_orders = []
        
        # Get best bid and ask
        if not data.bids or not data.asks:
            return
        
        best_bid = Decimal(str(data.bids[0].price))
        best_ask = Decimal(str(data.asks[0].price))
        
        # Calculate mid price
        mid_price = (best_bid + best_ask) / Decimal("2")
        
        # Calculate our quote prices
        spread_decimal = self.spread_bps / Decimal("10000")
        our_bid = mid_price * (Decimal("1") - spread_decimal)
        our_ask = mid_price * (Decimal("1") + spread_decimal)
        
        # Get current position
        position = ctx.position(self.instrument)
        
        # Place buy order if not too long
        if position < self.max_position:
            ctx.limit_order(
                self.instrument,
                OrderSide.Buy,
                float(self.order_size),
                float(our_bid)
            )
        
        # Place sell order if not too short
        if position > -self.max_position:
            ctx.limit_order(
                self.instrument,
                OrderSide.Sell,
                float(self.order_size),
                float(our_ask)
            )

4. Adaptive Market Making Strategy

Adjusts quotes based on inventory and volatility.

from decimal import Decimal
import statistics
from neleus import Strategy, StrategyContext, OrderBook, Bar, OrderSide

class AdaptiveMarketMaker(Strategy):
    """
    Advanced market maker that:
    - Adjusts spread based on volatility
    - Skews quotes based on inventory
    - Pulls quotes when position limit reached
    """
    
    def __init__(self, base_spread_bps=10, order_size=0.1, max_position=1.0):
        super().__init__()
        self.base_spread_bps = Decimal(str(base_spread_bps))
        self.order_size = Decimal(str(order_size))
        self.max_position = Decimal(str(max_position))
        
        self.instrument = None
        self.active_orders = []
        self.recent_prices = []
        self.volatility = Decimal("0.001")  # Default 0.1%
    
    def on_data(self, ctx: StrategyContext, data):
        # Update volatility estimate from bars
        if isinstance(data, Bar):
            self.instrument = data.instrument_id
            price = Decimal(str(data.close))
            self.recent_prices.append(price)
            
            if len(self.recent_prices) > 20:
                self.recent_prices = self.recent_prices[-20:]
                
                # Calculate returns
                returns = [
                    (self.recent_prices[i] - self.recent_prices[i-1]) / self.recent_prices[i-1]
                    for i in range(1, len(self.recent_prices))
                ]
                
                # Estimate volatility
                if len(returns) > 1:
                    self.volatility = Decimal(str(statistics.stdev([float(r) for r in returns])))
            
            return
        
        # Place quotes based on orderbook
        if not isinstance(data, OrderBook):
            return
        
        self.instrument = data.instrument_id
        
        # Cancel existing orders
        for order_id in self.active_orders:
            ctx.cancel_order(order_id)
        self.active_orders = []
        
        if not data.bids or not data.asks:
            return
        
        best_bid = Decimal(str(data.bids[0].price))
        best_ask = Decimal(str(data.asks[0].price))
        mid_price = (best_bid + best_ask) / Decimal("2")
        
        # Get current position
        position = ctx.position(self.instrument)
        inventory_ratio = position / self.max_position if self.max_position > 0 else Decimal("0")
        
        # Adjust spread based on volatility
        # Higher volatility = wider spread
        vol_multiplier = Decimal("1") + (self.volatility / Decimal("0.001"))
        adjusted_spread = self.base_spread_bps * vol_multiplier
        
        # Skew quotes based on inventory
        # Long inventory = lower bid, lower ask (want to sell)
        # Short inventory = higher bid, higher ask (want to buy)
        skew_bps = inventory_ratio * Decimal("5")  # 5 bps per 100% inventory
        
        spread_decimal = adjusted_spread / Decimal("10000")
        skew_decimal = skew_bps / Decimal("10000")
        
        our_bid = mid_price * (Decimal("1") - spread_decimal - skew_decimal)
        our_ask = mid_price * (Decimal("1") + spread_decimal - skew_decimal)
        
        # Place buy order if not at max long position
        if position < self.max_position * Decimal("0.9"):  # 90% buffer
            ctx.limit_order(
                self.instrument,
                OrderSide.Buy,
                float(self.order_size),
                float(our_bid)
            )
        
        # Place sell order if not at max short position
        if position > -self.max_position * Decimal("0.9"):
            ctx.limit_order(
                self.instrument,
                OrderSide.Sell,
                float(self.order_size),
                float(our_ask)
            )

Best Practices

1. Always Use Decimal for Prices

Floating-point arithmetic can introduce errors in financial calculations.

#   Wrong
price = 100.1 + 0.2  # May not equal exactly 100.3

#   Correct
price = Decimal("100.1") + Decimal("0.2")  # Exact

2. Keep State Minimal

Only store what you need. Rust handles positions, orders, and PnL for you.

3. Test Thoroughly

Always backtest before live trading:

$ neleus backtest --strategy mystrategy --start 2024-01-01 --end 2024-12-31

4. Handle Edge Cases

$ python examples/latency_benchmark.py

  • < 1μs: Simple strategies (price checks)

Performance Metrics

After running a backtest, Neleus provides comprehensive metrics:

Returns

  • Total Return: Overall profit/loss percentage
  • Annualized Return: Return scaled to yearly basis
  • Max Drawdown: Largest peak-to-trough decline

Risk-Adjusted Returns

  • Sharpe Ratio: Return per unit of risk (>1 is good)
  • Sortino Ratio: Return per unit of downside risk
  • Calmar Ratio: Return / Max Drawdown

Trading Statistics

  • Total Trades: Number of round-trip trades
  • Win Rate: Percentage of profitable trades
  • Profit Factor: Gross profit / Gross loss
  • Avg Trade PnL: Average profit/loss per trade
